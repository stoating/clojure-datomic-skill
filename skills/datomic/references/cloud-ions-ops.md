## Best-Practice Checks

- For Cloud, confirm setup order: AWS account, storage stack, compute stack, access/control.
- For Ions, separate local REPL development, push/deploy, entry points, and monitoring.
- For Pro, distinguish dev transactor setup from production storage, HA, backup, and monitoring.
- For capacity/performance, check memory/cache, query stats, tx stats, and monitoring docs together.
- For destructive operations, consult deleting/backup docs before suggesting action.
